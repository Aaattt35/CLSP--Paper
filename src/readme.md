## GitHub Actions: Automatic Test Execution

text

## Downloading the Example Output (Artifact)

1. Go to the **Actions** tab  
2. Open **Run Python Experiment**  
3. Select the latest run  
4. Scroll to **Artifacts**  
5. Download:
test-instance-results

text
Extract the ZIP and you will find:
test_instance_output.csv

## Source Code Summary

### model.py
- Defines decision variables  
- Builds constraints and objective  
- Calls the solver  
- Returns solution values and status  

### run_experiment.py
- Loads the instance file  
- Calls the model  
- Prints solver results  
- Saves the CSV file in `results/`

Execution flow:
run_experiment.py → model.py → solver → results/*.csv
