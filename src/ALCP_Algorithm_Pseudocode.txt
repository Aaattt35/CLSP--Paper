Algorithm 1: Difference In Profit (Δ)
========================================================================================
Input : Demands (d_1, ..., d_T), Capacities (Cap_1, ..., Cap_T), Cost Matrix (a)
Output: Del (Profit Difference)
----------------------------------------------------------------------------------------

1: procedure DELTA(t, r)
2:     q_[r](t)     ← Q-OPERATOR(Cap_t, t, r)
3:     q_[r+1](r)   ← Q-OPERATOR(Cap_r, r, r + 1)
4:     Del          ← ∑_{i=r}^{q_[r](t)} a_{ti} - ∑_{i=r+1}^{q_[r+1](r)} a_{ri}
5:     return Del
6: end procedure

7: procedure Q-OPERATOR(C, t, r)
8:     sp ← |∑_{j=1}^{T} d_j|
9:     
10:    if (C - d_t - ∑_{i=r}^{r+sp} d_i < 0) then
11:        while (sp ≥ 1 and Cap_t - ∑_{i=r}^{r+sp-1} d_i < 0) do
12:            sp ← sp - 1
13:        end while
14:        q ← sp + r - 1
15:    end if
16:    
17:    if (C - d_t - ∑_{i=r}^{r+sp} d_i ≥ 0) then
18:        while (sp < T - sp and Cap_t - ∑_{i=r}^{r+sp+1} d_i ≥ 0) do
19:            sp ← sp + 1
20:        end while
21:        q ← sp + r
22:    end if
23:    
24:    return q
25: end procedure

========================================================================================
Algorithm 2: Allocating Latest Consecutive Periods (ALCP)
========================================================================================
Input : Time horizon T, Unit costs a_{tj}, Demands d_t, Capacities Cap_t  (∀ 1 ≤ t < j ≤ T)
Output: \hat{m}_t (Optimal number of periods / bound for each t)
----------------------------------------------------------------------------------------

1:  procedure ALCP(T, a_{tj}, d_t, Cap_t)
2:      for t ← T - 1 down to 1 do
3:          Find the smallest r such that: DELTA(t, r + 1) < 0
4:          r*_t        ← r
5:          q_{r*_t}    ← Q-OPERATOR(Cap_t - d_t, t, r*_t)
6:          msen2_t     ← q_{r*_t} - t + 1
7:          q           ← q_{r*_t}
8:          
9:          Find the smallest p such that: DELTA(q, p + 1) < 0
10:         r*_q        ← p
11:         mv_one_t    ← r*_q - t + 1
12:         
13:         Build index set S = { r*_t, r*_t + 1, ..., q_[r*_t](t) }
14:         e           ← argmax_{s ∈ S} { r*_s }
15:         r*_e        ← max_{s ∈ S} { r*_s }
16:         rcC         ← Cap_t - d_t + d_e
17:         rcD         ← rcC
18:         S           ← S \ {e}
19:         ms          ← Q-OPERATOR(rcC, t, r*_t)
20:         
21:         while (ms < r*_e) do
22:             j ← argmin_{s ∈ S} { Cap_s }
23:             if (j < e) then
24:                 rcC ← rcC + Cap_j
25:                 ms  ← Q-OPERATOR(rcC, t, r*_t)
26:                 rcD ← rcD + d_j
27:                 S   ← S \ {j}
28:             end if
29:         end while
30:         
31:         ms°         ← Q-OPERATOR(rcD, t, r*_t)
32:         ap          ← ms° - q_{r*_t}
33:         mv_one_t    ← msen2_t + ap + 1
34:         \hat{m}_t   ← min(mv_one_t, mv_two_t)
35:     end for
36:     
37:     return \hat{m}_t
38: end procedure

## Theoretical Background & Worst-Case Bound Formulation

Assume period $t$ is a PRP (Production & Regeneration Period) and $q$ is also a PRP. The final scenario combines **Scenarios 2 and 3** to construct the **worst-case upper bound** on the coverage length $m^*_t$:

1. **Demand Pre-satisfaction:** Demands for periods $t+1$ through $r^*_t$ are assumed to be satisfied by production periods occurring prior to period $t$.
2. **Additional Production Periods (PPs):** Unlike earlier settings where coverage for period $t$ begins at $r^*_t$, here period $r^*_t$ itself remains a PP. To enforce the worst-case scenario, the maximum possible number of periods following $r^*_t$ are also assumed to become PPs.
3. **Capacity Reallocation:** Releasing capacity from these new PPs allows the production at period $t$ to satisfy demands in more distant periods, delaying the end point of coverage and providing a tight upper bound $\hat{m}_t$.

---

### Mathematical Definitions

- **Candidate Period Sequence:**
  Let $T_{r^*:q} = \{r^*_t, r^*_t + 1, \dots, q_{[r^*]}(t)\}$ denote the sequence of periods starting from $r^*_t$ to be covered by period $t$, where:
  $$q_{[r^*]}(t) = Q\left(RcD^0_t = RcC^0_t, \, t, \, r^*_t\right)$$

- **Critical Period ($e$):**
  Let $e$ be the period with the largest $r^*_j$ index within $T_{r^*:q}$:
  $$e = \arg\max_{j \in T_{r^*:q}} \{r^*_j\}$$

- **Sorted Capacity Subset ($T^{\downarrow}_{r^*:q}$):**
  Obtained by removing element $e$ from $T_{r^*:q}$ and ordering the remaining periods in non-decreasing order of capacity:
  $$T^{\downarrow}_{r^*:q} = \{t_{(n)} \mid cap_{t_{(n-1)}} \le cap_{t_{(n)}}\}, \quad \forall n = 2, 3, \dots, q_{[r^*]}(t) - r^*_t$$

- **Milestones for Step $k$:**
  For each step $k \in \{0, 1, \dots, q_{[r^*]}(t) - r^*_t\}$, define subset $T^k_{r^*:q} = \{t_{(1:k)}\}$. The corresponding coverage endpoints are:
  $$ms^{[0]}_{[k]} = Q\left(RcD^{t_{(1:k)}}_t, \, t, \, r^*_t\right)$$
  $$ms^{[k]}_{[k]} = Q\left(RcC^{t_{(1:k)}}_t, \, t, \, r^*_t\right)$$

- **Optimal Subset Size ($g^*$):**
  The minimal number of elements from $T^{\downarrow}_{r^*:q}$ required to delay coverage past $r^*_e$:
  $$g^* = \min \left\{ k \;\middle|\; ms^{[k]}_{[k]} > r^*_e, \; k \in T^{\downarrow}_{r^*:q} \right\}$$

- **Additional Periods & Upper Bound:**
  The maximum additional consecutive periods period $t$ can cover in the worst-case is:
  $$ap(t) = ms^{[0]}_{[g^*]} - q_{[r^*]}(t)$$
  Yielding the closed-form upper bound:
  $$\hat{m}_t = \left(q_{[r^*]}(t) - t + 1\right) + ap(t) + 1$$
